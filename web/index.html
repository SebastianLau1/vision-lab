Model & privacy notes

Live inference uses YOLOv8n with ONNX Runtime Web on your CPU. The first run downloads public model weights. Camera access requires permission and HTTPS. Frame rate depends on your device. Recorded footage uses a separate YOLO11n + ByteTrack pipeline; live boxes are detections, not persistent tracks.
